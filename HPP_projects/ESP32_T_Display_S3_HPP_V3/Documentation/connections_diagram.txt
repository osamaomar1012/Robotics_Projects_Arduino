================================================================================
METANOIA CARRIER BOARD PIN HEADER REFERENCE (2.54mm JST):
================================================================================
CONNECTOR J1 (MODULE VIN):
  Pin 1: GND      -> System Ground
  Pin 2: VOUT     -> Switched battery rail (3.0V - 4.2V) to T-Display-S3 5V pin

CONNECTOR J2 (MAIN POWER SWITCH):
  Pin 1: VOUT     -> Main switched power rail
  Pin 2: OUT_P    -> TP4056 protected battery output

CONNECTOR J3 (BRUSHED DC MOTOR):
  Pin 1: M1       -> MX1508 OUTB1 (JGA12-N20 Motor Terminal +, RED Wire)
  Pin 2: M2       -> MX1508 OUTA1 (JGA12-N20 Motor Terminal -, WHITE Wire)
  Note: Filter capacitor C7 (100nF) is installed across Pin 1 and Pin 2 for noise suppression.

CONNECTOR J4 (QUADRATURE ENCODER):
  Pin 1: GND      -> Ground (BLUE Wire)
  Pin 2: IO33     -> Channel A (YELLOW Wire) -> S3 GPIO 12 (Hardware Interrupt)
  Pin 3: IO32     -> Channel B (GREEN Wire)  -> S3 GPIO 11 (Direction Logic)
  Pin 4: +3.3V    -> Logic Supply (BLACK Wire) -> Regulated 3.3V

CONNECTOR J5 (SURGICAL LED ILLUMINATION):
  Pin 1: LEDS     -> Switched low-side return through N-Channel MOSFET Q1
  Pin 2: VOUT     -> Direct battery rail VOUT (3.0V - 4.2V)
  Note: External LED module must include internal current-limiting resistors.

================================================================================
TECHNICAL SPECIFICATIONS & SAFEGUARDS:
================================================================================
1. CURRENT SHUNT: High-side current sensing uses a 10mΩ (0.010Ω) precision resistor R2
   placed between VOUT and VDRIV. INA219 registers are calibrated with CAL=40960 (0xA000)
   to ensure 100µA/bit resolution up to 3.27A full-scale.

2. REVERSE POLARITY: Dual parallel AO3401A P-MOSFETs (Q2, Q3) provide ultra-low drop
   (< 80mV at 2A) reverse battery protection between 18650 holder BT1 and VBAT.

3. MOTOR SLEEP & STANDBY: 100kΩ pull-down resistors R1 and R3 hold MX1508 inputs
   low during boot, preventing spurious motor motion upon startup or reset.

4. USB CHARGING DETECTION:
   - Compares internal voltage on GPIO 4 (ADC1_CH3) and external INA219 bus readings.
   - When USB is connected, charger output voltage is detected, displaying
     the dynamic 'CHG' animation on screen and updating the web dashboard.
