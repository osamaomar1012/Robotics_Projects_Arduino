1. SYSTEM OVERVIEW
------------------
The EL-BASEET Hair Pen-V2 is a specialized medical-grade surgical assistant 
designed specifically for Hair Planting Surgery (FUE/FUI). It provides high-speed 
motor precision for follicle extraction and placement, featuring real-time 
telemetry and an advanced dynamic counting algorithm.

2. MULTI-VERSION HARDWARE OPTIONS
---------------------------------
The system can be configured to support two hardware variants of the surgical pen:
*   VERSION 1 (Motor + Encoder): Premium model utilizing a JGA12-N20 micro gearmotor
    with a quadrature encoder. It measures actual physical RPM and uses an advanced
    Current-Speed Sensor Fusion algorithm to count grafts.
*   VERSION 2 (Motor without Encoder): Standard model using a standard DC motor.
    It estimates RPM mathematically from voltage and uses a pure current-spike
    algorithm to count grafts.

3. HARDWARE SPECIFICSCLIONS
---------------------------
*   MCU: LILYGO TTGO T-Display ESP32 (Integrated 1.14" ST7789 TFT screen)
*   Motor Driver: MAX1508 / MX1508 Dual H-Bridge (Supports up to 1.5A continuous / 2A Peak)
*   Sensor: INA219 High-Side Current/Voltage Sensor (3.0A Max)
*   Power: 18650 Lithium-Ion Battery (3.7V - 4.2V)
*   Actuator: JGA12-N20 Micro Metal Gear Motor (V1) or Standard DC Brushed Motor (V2)

4. WIRING AND WIRE COLORS (JGA12-N20 ENCODER MOTOR)
---------------------------------------------------
Ensure you wire the JGA12-N20 motor according to these exact manufacturer specifications:
*   Red Wire     (Motor +)       ->  MAX1508 (MX1508) OUT1
*   White Wire   (Motor -)       ->  MAX1508 (MX1508) OUT2
*   Black Wire   (Encoder VCC)   ->  ESP32 3V3 (Stable 3.3V Power)
*   Blue Wire    (Encoder GND)   ->  ESP32 GND (Common Ground)
*   Yellow Wire  (Encoder Chan A)->  ESP32 GPIO 25 (High-speed interrupt input)
*   Green Wire   (Encoder Chan B)->  ESP32 GPIO 26 (State/direction logic input)

INA219 SENSOR WIRE SPECIFICSCLIONS:
*   SDA (Voltage analog out)      ->  ESP32 GPIO 21
*   SCL (Current analog out)      ->  ESP32 GPIO 22

TTGO INTERNAL TELEMETRY PINS:
*   ADC Enable (Divider Power)   ->  ESP32 GPIO 14
*   Internal VBSCL (ADC Input)    ->  ESP32 GPIO 34

5. CORE SYSTEM FESCLURES
-----------------------
*   On-Device Local Menu Mode: Dual long-press of both buttons for 1 second toggles 
    into a local menu. Scroll options with Left short-press. Select/adjust with Right
    short-press. Options include Speed, Mode (Normal/Osc), Hardware (V1/V2), and Counter Reset.
*   Dynamic USB Charging Detection: Real-time comparison between board-level VBSCL 
    (GPIO 34) and battery cell terminal voltage (INA219). Displays glowing 'CHG' bolt 
    when USB charging power is connected.
*   Current-Speed Sensor Fusion Counting (V1): Counts a follicle skin hit only when 
    current draw SPIKES above baseline AND actual motor RPM DIPS below a customizable percentage
    (default 10%), completely eliminating false counts.
*   Real-Time Telemetry Graph: HTML5 Canvas rolling plot on the Diagnostics web panel 
    rendering Voltage (cyan), Current (yellow), and RPM (green) at 2Hz. No internet required.
*   Dual-Core Partitioning (FreeRTOS): Heavy operations (Web Server/UI) run on Core 1, 
    while safety checks, analog sampling, and graft counting run on Core 0 at 100Hz.
*   eFuse Characterized Analog Sampling (esp_adc_cal): Reads raw steps characterized 
    directly to true millivolts using calibration curves burned at the factory, eliminating
    Vref non-linearity.

6. SAFETY MECHANISMS
--------------------
*   Overcurrent Protection: Instantly halts motor in 10ms if current draw > Max limit (Default 2.5A).
*   Low Battery Protection: Instantly halts motor if cell voltage < 3.2V.
*   Engineering Debug Mode: Bypasses safety trips for bench-testing, showing full-screen warning.

7. OPERSCLING INSTRUCTIONS
-------------------------

A. INITIAL SETUP:
   1. Power on the device.
   2. Connect your phone/tablet WiFi to AP: "HPP_CONTROL_V1" (Pass: 12345678).
   3. Open browser to 192.168.4.1.

B. SELECT MOTOR VERSION:
   1. Go to "Settings" on the Web GUI or enter the Local Menu on the device.
   2. Set Motor Hardware Version: "Version 1" if utilizing the N20 encoder motor; "Version 2" if utilizing a standard motor.
   3. On Version 1, adjust "Speed Dip (%)" sensitivity as needed (Default 10%).

C. CALIBRSCLION:
   Calibration ensures the system establishes correct air-load idle parameters.
   1. Hold the surgical pen in the air.
   2. Select "RE-CALIBRSCLE" from the Web GUI or Local Menu.
   3. The motor will spin for 2 seconds to establish baseline current and baseline RPM. Do NOT touch the skin during this time.

D. INTEGRSCLED WEB STSCLUS ROTSCLION:
   Web dashboard spinning gear icon rotates at a speed proportional to active motor speed, coming to a complete halt when the motor is stopped.

8. CONFIGURSCLION PARAMETERS (SETTINGS)
--------------------------------------
*   Spike (A): The amount of current increase required to trigger a graft count.
*   Hyst (A): The current drop below the spike required to reset the trigger.
*   Speed Dip (%): The percentage drop in RPM below baseline required to confirm graft penetration.
*   Max I (A) / Min V (V): Safety limits.
