1. SYSTEM OVERVIEW
------------------
The EL-BASEET Hair Pen-V2 is a specialized medical-grade surgical assistant 
designed specifically for Hair Planting Surgery (FUE/FUI). It provides high-speed 
motor precision for follicle extraction and placement, featuring real-time 
telemetry and an advanced dynamic counting algorithm.

2. MULTI-VERSION HARDWARE OPTIONS
---------------------------------
The system can be configured to support two hardware variants of the surgical pen:
*   VERSION 1 (Motor + Encoder): Premium model utilizing a JGA12-N20 micro gearmotor
    with a quadrature encoder. It measures actual physical RPM and uses an advanced
    Current-Speed Sensor Fusion algorithm to count grafts.
*   VERSION 2 (Motor without Encoder): Standard model using a standard DC motor.
    It estimates RPM mathematically from voltage and uses a pure current-spike
    algorithm to count grafts.

3. HARDWARE SPECIFICATIONS
--------------------------
*   Carrier Board: Metanoia Motor Control Carrier Board (Rev A, KiCad 10)
*   MCU Module: LILYGO TTGO T-Display ESP32 (Integrated 1.14" ST7789 TFT screen)
*   Motor Driver: Onboard MX1508 Dual H-Bridge (Supports up to 1.5A continuous / 2A Peak)
*   Current / Voltage Sensor: INA219 across 10mΩ High-Side Shunt R2 (Address 0x40)
*   Power Source: Single 18650 Li-ion Battery with Dual AO3401A Ideal-Diode Reverse Protection
*   Battery Charging: Integrated TP4056 1A Charger with Under-Voltage/Over-Current Protection & USB-C
*   Actuator: JGA12-N20 Micro Metal Gear Motor with Quadrature Encoder (V1) or Standard DC Brushed Motor (V2)

4. WIRING AND WIRE COLORS (METANOIA PIN HEADERS):
-------------------------------------------------
All connections plug directly into the dedicated 2.54mm headers on the carrier board:

CONNECTOR J3 (BRUSHED DC MOTOR):
*   Red Wire     (Motor Terminal +) -> J3 Pin 1 (M1, MX1508 OUTB1)
*   White Wire   (Motor Terminal -) -> J3 Pin 2 (M2, MX1508 OUTA1)
*   Motor Control Pins: INA1 -> TTGO GPIO 13 (PWM), INB1 -> TTGO GPIO 25 (PWM)

CONNECTOR J4 (JGA12-N20 QUADRATURE ENCODER):
*   Black Wire   (Encoder VCC)      -> J4 Pin 4 (+3.3V Regulated Power)
*   Yellow Wire  (Encoder Chan A)   -> J4 Pin 2 (Net IO33 -> TTGO GPIO 33, Hardware Interrupt)
*   Green Wire   (Encoder Chan B)   -> J4 Pin 3 (Net IO32 -> TTGO GPIO 32, Direction State)
*   Blue Wire    (Encoder GND)      -> J4 Pin 1 (System Ground)

CONNECTOR J5 (SURGICAL LED ILLUMINATION):
*   Pin 1 (LEDS Return)             -> Low-Side Switched Cathode (Driven by Q1 / TTGO GPIO 17)
*   Pin 2 (VOUT Supply)             -> Positive Anode Supply (Switched Battery Rail, 3.0V - 4.2V)
*   Note: External LED module must include internal current-limiting resistors.

CONNECTOR J2 (MAIN POWER SWITCH):
*   Pin 1 (VOUT)                    -> Main switched system power rail
*   Pin 2 (OUT_P)                   -> TP4056 protected battery output

CONNECTOR J1 (TTGO VIN):
*   Pin 1 (GND)                     -> System Ground
*   Pin 2 (VOUT)                    -> Switched Battery Rail to TTGO 5V Power Input

INA219 SENSOR ROUTING:
*   SDA (I2C Data)                  -> Net SDA -> TTGO GPIO 21 (Carrier Pad 15, 4.7kΩ pull-up R4)
*   SCL (I2C Clock)                 -> Net SCL -> TTGO GPIO 22 (Carrier Pad 16, 4.7kΩ pull-up R5)

TTGO ONBOARD TELEMETRY & CONTROLS:
*   ADC Enable (Divider Gate)       -> TTGO GPIO 14 (Active HIGH)
*   Internal VBAT (ADC Input)       -> TTGO GPIO 34 (ADC1_CH6, 100k/100k divider)
*   Left Button (Navigation)        -> TTGO GPIO 0 (Active LOW)
*   Right Button (Selection)        -> TTGO GPIO 35 (Active LOW)

5. CORE SYSTEM FESCLURES
-----------------------
*   On-Device Local Menu Mode: Dual long-press of both buttons for 1 second toggles 
    into a local menu. Scroll options with Left short-press across 6 items. Select/adjust with Right
    short-press. Options include Speed, LED Light (OFF, 25%, 50%, 75%, 100%), Mode (Normal/Osc), Hardware (V1/V2), Counter Reset, and Exit Menu.
*   Quick LED Illumination Toggle: Quick dual tap (short press of both buttons) toggles 
    the surgical LED headlight ON (100%) or OFF immediately without opening the menu.
*   Surgical Illumination Control (Pin 17): High-frequency 5kHz flicker-free LED PWM control 
    adjustable via the Web Dashboard slider/presets, In-Operation surgical interface, Settings panel, 
    and local OLED display menu. Brightness is saved in non-volatile memory (NVM).
*   Dynamic USB Charging Detection: Real-time comparison between board-level VBSCL 
    (GPIO 34) and battery cell terminal voltage (INA219). Displays glowing 'CHG' bolt 
    when USB charging power is connected.
*   Current-Speed Sensor Fusion Counting (V1): Counts a follicle skin hit only when 
    current draw SPIKES above baseline AND actual motor RPM DIPS below a customizable percentage
    (default 10%), completely eliminating false counts.
*   Real-Time Telemetry Graph: HTML5 Canvas rolling plot on the Diagnostics web panel 
    rendering Voltage (cyan), Current (yellow), and RPM (green) at 2Hz. No internet required.
*   Dual-Core Partitioning (FreeRTOS): Heavy operations (Web Server/UI) run on Core 1, 
    while safety checks, analog sampling, and graft counting run on Core 0 at 100Hz.
*   eFuse Characterized Analog Sampling (esp_adc_cal): Reads raw steps characterized 
    directly to true millivolts using calibration curves burned at the factory, eliminating
    Vref non-linearity.

6. SAFETY MECHANISMS
--------------------
*   Overcurrent Protection: Instantly halts motor in 10ms if current draw > Max limit (Default 2.5A).
*   Low Battery Protection: Instantly halts motor if cell voltage < 3.2V.
*   Engineering Debug Mode: Bypasses safety trips for bench-testing, showing full-screen warning.

7. OPERATING INSTRUCTIONS
-------------------------

A. INITIAL SETUP & STARTUP ANIMATION:
   1. Power on the device.
   2. The high-definition Welcome Animation (70 frames) plays automatically on the TFT display.
   3. Connect your phone/tablet WiFi to AP: "HPP_CONTROL_V2" (Pass: 12345678).
   4. Open browser to http://elbaseet.local.

B. OPERATION CONTROLS & ANIMATIONS:
   *   START OPERATION:
       - Web: Click "START OPERATION" button on the dashboard.
       - Device: Long-press Right Button (1 second) while in IDLE state.
       - Effect: Displays the Hair Transplant Animation (68 frames) on the TFT screen,
         starts procedure timers, and transitions operation to RUNNING mode.
   *   PAUSE / RESUME OPERATION:
       - Pause: Long-press Left Button while RUNNING to pause timer and motor.
       - Resume: Long-press Right Button while PAUSED to resume procedure.
   *   STOP OPERATION:
       - Web: Click "STOP OPERATION" button on the dashboard.
       - Device: Long-press Left Button while in PAUSED state.
       - Effect: Displays the Hair Animation (60 frames) on the TFT screen,
         halts the motor, saves the final graft count and JSON report to SPIFFS.
   *   GENERATE REPORT:
       - Web: Click "GENERATE REPORT" or open report preview.
       - Effect: Displays the Report Animation (25 frames) on the TFT screen,
         providing visual confirmation of report compilation and storage.
   *   FAST ANIMATED SCREENSAVER:
       - When idle for >15 seconds, the TFT screen enters screensaver mode,
         smoothly cycling through the hair animation at ~33 FPS alongside real-time clock and battery status.

C. SELECT MOTOR VERSION:
   1. Go to "Settings" on the Web GUI or enter the Local Menu on the device.
   2. Set Motor Hardware Version: "Version 1" if utilizing the N20 encoder motor; "Version 2" if utilizing a standard motor.
   3. On Version 1, adjust "Speed Dip (%)" sensitivity as needed (Default 10%).

D. CALIBRATION:
   Calibration ensures the system establishes correct air-load idle parameters.
   1. Hold the surgical pen in the air.
   2. Select "RE-CALIBRATE" from the Web GUI or Local Menu.
   3. The motor will spin for 2 seconds to establish baseline current and baseline RPM. Do NOT touch the skin during this time.

E. INTEGRATED WEB STATUS ROTATION:
   Web dashboard spinning gear icon rotates at a speed proportional to active motor speed, coming to a complete halt when the motor is stopped.

8. CONFIGURSCLION PARAMETERS (SETTINGS)
--------------------------------------
*   Spike (A): The amount of current increase required to trigger a graft count.
*   Hyst (A): The current drop below the spike required to reset the trigger.
*   Speed Dip (%): The percentage drop in RPM below baseline required to confirm graft penetration.
*   Max I (A) / Min V (V): Safety limits.
