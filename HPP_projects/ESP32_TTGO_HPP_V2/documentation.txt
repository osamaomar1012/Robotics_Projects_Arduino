1. HARDWARE COMPONENT VARIANTS:
-------------------------------
The unified firmware binary dynamically supports two surgical pen variants:
- VERSION 1: Premium Follicle Extractor
  * Actuator: JGA12-N20 Micro Metal Gear 6V DC Motor with Quadrature Encoder.
  * Counter: Current-Speed Sensor Fusion (INA219 spike + Encoder speed dip).
  * Speed: Real physical RPM measured by high-speed hardware interrupts.
- VERSION 2: Standard Follicle Extractor
  * Actuator: Standard DC Brushed Motor (No Encoder).
  * Counter: Pure Current-Spike Detection.
  * Speed: Estimated RPM proportional to applied motor voltage.

2. PIN MAPPING (ESP32 TTGO T-Display):

-----------------|------|------------------|------------------------------------

Encoder VCC      | 3V3  | Black            | Encoder Power (3.3V)

3. HARDWARE CONNECTION FLOW:
----------------------------
18650 LI-ION CELL:
  Positive (+)   -> INA219 SENSOR [VIN+] AND TTGO VBSCL connector pin
  Negative (-)   -> ESP32 GND (Common Ground)

INA219 SENSOR:
  [VIN+]          -> Battery Positive (+)
  [VIN-]          -> MAX1508 (MX1508) VCC
  [GND]          -> Common Ground
  [SDA]           -> ESP32 GPIO 21
  [SCL]           -> ESP32 GPIO 22

MAX1508 (MX1508) MOTOR DRIVER:
  [VCC]          -> INA219 VIN-
  [GND]          -> Common Ground
  [IN1]          -> ESP32 GPIO 13
  [IN2]          -> ESP32 GPIO 27
  [OUT1]         -> JGA12-N20 Motor Terminal (+) [Red Wire]
  [OUT2]         -> JGA12-N20 Motor Terminal (-) [White Wire]

4. REAL-TIME MULTI-CORE WORKPARTITIONING:
-----------------------------------------
To ensure medical-grade counting reliability and instantaneous safety stops, the system distributes processes across dual cores via FreeRTOS:
- CORE 0 (Background task, 100Hz high-priority loop):
  * Sampling: Characterized INA219 analog inputs.
  * Safety: 10ms overcurrent trip (max 2.5A) and low battery cutoff.
  * Motion: Soft-start speed ramping and alternating FUE oscillation.
  * Counting: Current-Speed Sensor Fusion follicle counting.
- CORE 1 (Standard main loop & server context):
  * UI: Multi-screen rotation and welcoming animations.
  * Inputs: Dual-button press debouncing.
  * Network: AP and Station asynchronous Web Server.

5. CHARACTERIZED ANALOG SYSTEM (esp_adc_cal):
----------------------------------------------
The system completely bypasses uncalibrated raw analog reads. It uses the ESP32 characterization API to read Vref calibration curves burned into the eFuse at the factory.
- SDA Analog (SDA): `esp_adc_cal_raw_to_voltage` maps GPIO 21 raw readings directly to millivolts, divided by 1000 and scaled by 5.0.
- SCL Analog (SCL): Characterizes GPIO 22 directly to millivolts, mapped linearly to Amperes (1000mV = 1.0A).
- VBSCL Analog: Gated by GPIO 14, characterizing GPIO 34 directly to millivolts, scaled by 2.0 (100k/100k onboard divider).

6. CORE SYSTEM FESCLURES:
-------------------------
- On-Device Local Menu: Triggered by a dual long press of both buttons. Left scrolls, Right selects. Adjusts speed, mode, motor version, and resets counting on-device.
- Differential Charging: Compares internal VBSCL (GPIO 34) and external battery cell voltage (INA219) to dynamically detect USB power, showing the charging icon (CHG) on the TFT screen.
- Web Diagnostics Scope: HTML5 Canvas-based rolling plot rendering real-time scrolling Voltage, Current, and RPM at 2Hz on the diagnostics panel without internet connectivity.
- Proportional Web Logo: Dashboard rotating gear animation spins at a speed proportional to actual motor speed, stopping when the motor halts.

APPENDIX: SENSOR FUSION GRAFT COUNTING LOGIC
================================================================================
This diagram illustrates the real-time algorithm (executed at 100Hz) used to 
detect skin penetration and accurately count grafts without false positives.

It utilizes the digital I2C INA219 sensor (Current) and the N20 Encoder (RPM).

[TIMELINE] ----> Time (Penetration Cycle) ---->

                [1] IDLE / FREE AIR        [2] PENETRATION (SCALP)        [3] WITHDRAWAL
                ---------------------      -----------------------        ---------------------
         
         (A) ++++++++++++++++++++++++++     ...      ...      ...      ++++++++++++++++++++++++++
   Motor     |                        |    /   \    /   \    /   \    /                         |
    RPM      |  (Calibrated Baseline) |___/     \__/     \__/     \__/ (Returns to Baseline)    |
             |                        |   (RPM DIPS > 10% THRESHOLD)                            |
         (0) +------------------------+---------------------------------------------------------+
                                      |                              |
                                      V     [ SENSOR FUSION ]        V
                                      |                              |
         (A) +------------------------+------------------------------+--------------------------+
             |                        |                              |                          |
             |                        |         _.--._         |                          |
    INA219   |----[SPIKE THRESHOLD]---|-------.'------------'.-------|--------------------------|
   Current   |                        |      /                \      |                          |
             |----[EXIT / HYSTERESIS]-|-----/------------------\-----|--- (Count +1 Trigger)    |
             |                        |    /                    \    |                          |
             |  (Calibrated Baseline) |___/                      \___| (Returns to Baseline)    |
         (0) ++++++++++++++++++++++++++                              ++++++++++++++++++++++++++
                                          ^                          ^
                                      [STATE: isPenetrating = TRUE]  |
                                                                [STATE: isPenetrating = FALSE]
                                                                [ACTION: penetrationCount++]

LOGIC BREAKDOWN:
1. IDLE: The system stabilizes and calibrates 'Baseline RPM' and 'Baseline Current'.
2. PENETRATION: As the pen presses into the scalp, mechanical resistance increases.
   - Condition A (Current Spike): The INA219 detects Amperage crossing the [SPIKE THRESHOLD].
   - Condition B (RPM Dip): The Encoder detects RPM dipping >10% below [Baseline RPM].
   - Fusion Result: Both conditions are met. The system locks 'isPenetrating' to TRUE.
3. WITHDRAWAL: As the pen is removed, mechanical resistance drops.
   - Condition C (Exit Hysteresis): Current drops below the lower [EXIT THRESHOLD].
   - Result: The system unlocks 'isPenetrating', registers a single valid count (+1), 
     and flashes the OLED display. The Hysteresis gap prevents double-counting from hand tremors.
