1. HARDWARE COMPONENT ARCHITECTURE:
-----------------------------------
The system integrates onto the custom Metanoia Motor Control Carrier Board (Rev A):
- Carrier Controller Socket (U1): Dual 12-pin header (2x12 footprint) accepting
  either the classic TTGO T-Display or LilyGO T-Display-S3.
- Integrated Battery Power: Single 18650 Li-ion cell (BT1, Keystone 1042P) with
  dual-MOSFET ideal-diode reverse polarity protection (Q2, Q3: AO3401A P-MOSFETs).
- Charger Subsystem (U2): TP4056 1A Li-ion charger with integrated cell protection
  and external USB-C port.
- Power Switch (J2): Two-pin header in series between TP4056 OUT+ and main VOUT rail.
- Motor Driver (U4): MX1508 Dual H-Bridge (Channel 1 utilized), powered from VDRIV.
  Input lines INA1 / INB1 held low during boot via 100kΩ pull-downs R1 and R3.
- Power Monitor (U5): INA219 I2C current/power monitor across 10mΩ high-side shunt R2,
  measuring motor voltage, current, and power independently from system logic.
- Switched LED Driver (Q1): Logic-level N-Channel MOSFET (AO3400A) low-side switch
  driven via 47Ω gate resistor R6 and 10kΩ gate pull-down R7.

3. EXTERNAL PIN HEADERS (2.54mm JST):
-------------------------------------
- J1 (TTGO VIN):
  Pin 1: GND | Pin 2: VOUT (Alternative direct module power feed)
- J2 (Main Switch):
  Pin 1: VOUT | Pin 2: OUT_P (Connects external toggle switch in series)
- J3 (Motor):
  Pin 1: M1 (OUTB1, Red Wire) | Pin 2: M2 (OUTA1, White Wire) | C7 100nF filter
- J4 (Encoder):
  Pin 1: GND (Blue) | Pin 2: IO33 (Yellow) | Pin 3: IO32 (Green) | Pin 4: +3.3V (Black)
- J5 (LEDs):
  Pin 1: LEDS (Switched ground return via Q1) | Pin 2: VOUT (Battery rail)

4. REAL-TIME MULTI-CORE WORKPARTITIONING:
-----------------------------------------
Distributed across dual Xtensa cores via FreeRTOS:
- CORE 0 (Background task, 100Hz high-priority loop):
  * Sampling: INA219 digital voltage and current readings at 100Hz.
  * Safety: 10ms overcurrent trip (max 2.5A) and low battery cutoff (< 3.2V).
  * Motion: Soft-start speed ramping and alternating FUE oscillation.
  * Counting: Current-Speed Sensor Fusion follicle counting.
- CORE 1 (Standard main loop & server context):
  * UI: Multi-screen rotation, graphical motor telemetry, welcoming animations.
  * Inputs: Dual-button press debouncing and on-device menu navigation.
  * Network: Captive Portal AP ("HPP_CONTROL_V2") and Station Web Server.

5. SENSOR FUSION GRAFT COUNTING ALGORITHM:
------------------------------------------
Detects skin penetration and accurately registers follicle extraction without false counts:
1. IDLE / AIR LOAD: System stabilizes and calibrates 'Baseline Current' and 'Baseline RPM'.
2. PENETRATION: When the pen engages tissue, mechanical resistance rises:
   - Condition A: INA219 current SPIKES above [baselineCurrent + penetrationOffset].
   - Condition B: N20 optical/magnetic encoder detects RPM DIPPING > 10% below baseline.
   - Fusion Result: Both conditions confirm true skin penetration, locking isPenetrating = TRUE.
3. WITHDRAWAL: When the needle exits the scalp:
   - Current falls below the hysteresis threshold [Spike - penetrationHysteresis].
   - Lock releases, graft count increments (+1), and OLED/Web flash visual confirmations.
